# qa-webdriverio-tests
WebDriverIO is a JavaScript framework, similar to Playwright, that uses Mocha and JavaScript to test web pages and mobile apps. I've included a file, login.e2e.js. This file can be run using "npx wdio run ./wdio.conf.js --spec login.e2e.js" in command prompt. It will check that the home page on Google.com has a title element containing the text "Google".

More information here:
https://webdriver.io/docs/gettingstarted
